==================================================
HOW TO TEST
==================================================

1. Open the live application.
2. Save an accessibility profile.
3. Paste one of the tested event links above.
4. Run the accessibility check.
5. Review:
   - Event Details
   - Accessibility statuses
   - Recommended action
   - Request draft, when applicable

Important:
- Accessly runs in TEST MODE.
- Test emails are redirected to a controlled test inbox.
- No real organizer receives test messages.
- Real organization forms are never finally submitted during testing.
- If Accessly cannot verify information from an official source, it reports Unknown instead of guessing.
